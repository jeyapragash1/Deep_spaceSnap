# 🚀 Deep Space Snap

## 📌 Overview

Deep Space Snap is a space-themed web application that displays stunning astronomical images using external APIs.
It allows users to explore daily space images with descriptions in a clean and interactive interface.

## ✨ Features

* 🌌 Fetches real-time space images from API
* 📅 Daily astronomy picture viewer
* 📝 Image descriptions and metadata
* 🎨 Clean and responsive UI
* ⚡ Fast loading and dynamic updates

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* API: NASA APOD API (or your API)
* Version Control: Git & GitHub
